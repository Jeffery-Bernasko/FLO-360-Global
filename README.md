# FLO 360 Global — Warehouse Inventory & Approval App

Web app for a sanitary-products warehouse in Ghana. Tracks boxes (24 pcs/box) coming in from overseas suppliers and going out to customers, with a manager-approval workflow.

See [issue #1](https://github.com/Jeffery-Bernasko/FLO-360-Global/issues/1) for the master PRD and issues #2–#10 for the feature breakdown.

## Status

Pre-implementation. Foundation (F1) lands the project scaffold, database, auth, RBAC, and audit log.
